# Skill: Aura Sagrada

## 1. Informações Básicas
* **Classe:** Sacerdote (Base)
* **Tipo:** Habilidade Passiva
* **Custo de Mana:** 0
* **Recarga (Cooldown):** Passivo

## 2. Condição de Uso (Auto-Battler)
Aliados próximos.

## 3. Efeito
O Sacerdote emite uma aura de 3 tiles. Todos os aliados dentro da aura ganham +10% de Defesa Mágica.
