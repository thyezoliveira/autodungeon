# Skill: Clone Espelhado

## 1. Informações Básicas
* **Classe/Subclasse:** Mago / Ilusionista
* **Tipo:** Ativa
* **Custo de Mana:** 30
* **Recarga (Cooldown):** 18s

## 2. Condição de Uso (Auto-Battler)
Quando alvo de ataque

## 3. Efeito
Cria 2 clones do Ilusionista que não causam dano, mas recebem aggro dos inimigos.
