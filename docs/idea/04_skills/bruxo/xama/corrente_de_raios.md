# Skill: Corrente de Raios

## 1. Informações Básicas
* **Classe/Subclasse:** Bruxo / Xama
* **Tipo:** Ativa
* **Custo de Mana:** 25
* **Recarga (Cooldown):** 10s

## 2. Condição de Uso (Auto-Battler)
Inimigos próximos entre si

## 3. Efeito
Raios pulam entre até 3 inimigos causando dano mágico que diminui a cada pulo.
