# Skill: Pacto de Sangue

## 1. Informações Básicas
* **Classe:** Bruxo (Base)
* **Tipo:** Habilidade Passiva
* **Custo de Mana:** 0
* **Recarga (Cooldown):** Passivo

## 2. Condição de Uso (Auto-Battler)
Constante.

## 3. Efeito
Converte 10% de todo o Dano Mágico causado pelo Bruxo em cura para si mesmo (Spell Vamp).
