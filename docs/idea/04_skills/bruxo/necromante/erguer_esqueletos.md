# Skill: Erguer Esqueletos

## 1. Informações Básicas
* **Classe/Subclasse:** Bruxo / Necromante
* **Tipo:** Ativa
* **Custo de Mana:** 20
* **Recarga (Cooldown):** 15s

## 2. Condição de Uso (Auto-Battler)
Cadáver inimigo presente

## 3. Efeito
Invoca 2 guerreiros esqueletos frágeis que atraem ataques inimigos.
