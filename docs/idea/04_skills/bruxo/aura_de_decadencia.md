# Skill: Aura de Decadência

## 1. Informações Básicas
* **Classe:** Bruxo (Base)
* **Tipo:** Habilidade Passiva
* **Custo de Mana:** 0
* **Recarga (Cooldown):** Passivo

## 2. Condição de Uso (Auto-Battler)
Constante para inimigos próximos.

## 3. Efeito
Reduz passivamente a Defesa Mágica de todos os inimigos num raio curto em 15%.
