# Skill: Armadilha de Espinhos

## 1. Informações Básicas
* **Classe/Subclasse:** Arqueiro / Cacador
* **Tipo:** Ativa
* **Custo de Mana:** 15
* **Recarga (Cooldown):** 10s

## 2. Condição de Uso (Auto-Battler)
Inimigo se aproxima

## 3. Efeito
Lança uma armadilha no chão. Inimigos que pisarem sofrem Sangramento por 5s.
